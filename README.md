# 台股紙上交易實驗

用假的 10 萬台幣，從 **2026-10-22 開盤**起往後跑「前向」紙上交易：每天收盤後自動抓資料、算訊號，**隔天開盤價**成交，並和「買進持有 0050」比較。不做歷史績效回測，也不拿歷史資料調參數。

四個獨立的虛擬帳戶（各 10 萬）：

| 帳戶 | 邏輯 |
|---|---|
| A 趨勢動能 | 站上 20/60 日均線且 20 日漲幅排前 5 → 買；跌破 20 日均線或虧損 8% → 賣 |
| B 均值回歸 | 長多（站上 200 日均線）且 RSI(14) < 30 → 買；RSI ≥ 50 或持有滿 15 日 → 賣 |
| C 法人籌碼 | 外資連續 3 日買超且站上 20 日均線 → 買；外資連續 2 日賣超或跌破 20 日均線 → 賣 |
| D 對照組 | 開跑第一天全額買進 0050，之後不動 |

標的池是 0050 成分股 50 檔（開跑時固定）；A/B/C 最多同時持有 5 檔、每檔約等分資金、零股交易。成本：手續費 0.1425% × 6 折（最低 1 元）、賣出證交稅 0.3%（ETF 0.1%）。所有規則與參數都在 `config.py` 與 `strategies.py`，**實驗開始後不要改**（程式會偵測到參數被改而拒絕執行）。

## 設定步驟（約 10 分鐘）

1. 在 GitHub 新增一個**公開**儲存庫（例如 `tw-paper-trader`）。Pages 在免費帳號只支援公開儲存庫；這裡沒有任何敏感資料，只有虛擬帳戶的紀錄。
2. 把這個資料夾的內容推上去（注意要包含隱藏資料夾 `.github/`）。
3. **Settings → Actions → General → Workflow permissions** 選 *Read and write permissions*（讓排程能把每天的結果存回儲存庫）。
4. **Settings → Pages**：Source 選 *Deploy from a branch*，Branch 選 `main`、資料夾選 `/docs`。幾分鐘後網址是 `https://<你的帳號>.github.io/<儲存庫名>/`。
5. **先做資料來源檢查**：Actions 分頁 → `daily-paper-trade` → Run workflow → 勾選 `selftest` → 執行。確認價格與法人資料都顯示 OK。
6. （選用）到 [FinMind](https://finmindtrade.com/) 免費註冊拿 token，存成儲存庫的 Secret `FINMIND_TOKEN`，可以提高請求額度；沒有也能跑。

之後每個週一到週五台灣時間 22:00 自動執行；也可以隨時手動 Run workflow。

## 運作方式與保證

- 每天收盤後只用「當天以前」的資料算訊號，下一個交易日**開盤價**成交；漲停開盤買不到、跌停開盤賣不掉都會跳過。
- 某天漏跑不要緊，下次執行會自動補算所有新的交易日，結果和每天都有跑完全一樣（有測試驗證）。
- 最新一天的證交所法人資料若還沒公布，會先處理到前一天，下次補上。
- 起始日之前手動執行不會提前開始；要等到 2026-10-22 的資料出現才建立起始狀態。
- 價格報酬、不含股利，四個帳戶一致（所以 0050 的股利收益被低估）。

## 怎麼解讀結果

- 1 個月內的名次幾乎都是運氣；至少看 3 個月以上，並且每個策略累積數十筆平倉交易後再比較。
- 一定要和 D（0050）比：贏不了 0050 就表示這套邏輯扣掉成本後沒有價值。
- 留意「成本佔本金」：交易越頻繁，手續費與稅吃掉越多。

## 本機執行與測試

```bash
pip install -r requirements.txt
python tests/test_engine.py        # 引擎測試（模擬資料）
python tests/test_run_daily.py     # 每日流程測試（假資料來源）
python run_daily.py --selftest     # 檢查資料來源（需要網路）
python run_daily.py                # 正式更新
```

專案結構：`engine.py` 引擎（成交、成本、指標）、`strategies.py` 策略規則、`data.py` 資料抓取（FinMind / Yahoo / 證交所 T86）、`render.py` + `web/template.html` 網頁、`state/state.json` 帳戶狀態、`data/inst_foreign.csv` 外資買賣超快取、`docs/` 發布的頁面。

> 這是研究與教育用的模擬，不是投資建議。
